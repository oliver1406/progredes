# Revisão independente — instalação e bootstrap Microlab

Data: 28/10/2026. Escopo: os originais confirmados em `work/originals/`. GitHub é a fonte oficial e Gitea + runner permanecem no laboratório, conforme esclarecimento do usuário. Esta revisão não instalou pacotes, não alterou o host, não acessou servidor nem mudou os originais.

## Conclusão

Os arquivos apresentam uma intenção arquitetural coerente, mas não constituem ainda um pacote instalável e verificável. Há dependências ausentes, resultados anunciados sem observação da saúde, risco de falha após reboot e condições de reexecução que podem deixar endereços divergentes. Os pontos abaixo devem ser corrigidos antes da demonstração no Debian.

## Observações que não devem virar falsos defeitos

- `ServerActive` e `Hostname` configurados a partir do mesmo `hostname -s` utilizado no bootstrap são compatíveis com o desenho de agente ativo. A configuração real do agente e o host efetivamente escolhido ainda precisam ser observados.
- Publicar `10051` e manter `ListenIP=127.0.0.1` no agente não é, por si, erro: o agente ativo inicia a conexão ao servidor. O servidor não precisa acessar `10050` do host para esses itens.
- O uso de `Authorization: Bearer` não foi apontado como defeito: é mecanismo suportado na API Zabbix 7.0. Deve ser testado com a versão e o frontend escolhidos.
- Todos os três scripts anexados têm LF e não têm BOM. Não há evidência de defeito CRLF nesses originais.
- Instalação automática oficial de Tailscale via shell e grupo Docker são escolhas operacionais que precisam ser explicadas, mas não tornam sozinhas o laboratório inválido. Os executores precisam ser tratados como administradores do host quando compartilham daemon.

4. Consulta às fontes oficiais listadas nos achados. Nenhum conteúdo externo foi executado.
5. Não foi verificada disponibilidade atual dos pacotes/imagens, execução de Docker, instalação Debian, autenticação real, coleta Zabbix, registro de runner, firewall efetivo ou comportamento de reboot. Essas evidências devem vir de VM de homologação; revisão estática não as substitui.
